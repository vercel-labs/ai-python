Most agent APIs are documented as top-level `ai` exports. Use `ai.agents`
for advanced agent namespace APIs and types that are not promoted to the
top-level namespace.

## Aggregators

Aggregators collect yielded values from streaming tools and decide what value is
stored and what value is sent back to the model.

APIs:

- `Aggregate`
- `yield_from`
- `SimpleAggregator`
- `ConcatAggregator`
- `LastAggregator`
- `MessageAggregator`

Custom aggregators implement `ai.events.Aggregator`.

`yield_from` forwards values from an async iterable and returns the
aggregator's model-facing result.

```python
result = await ai.agents.yield_from(
    stream,
    aggregator=ai.agents.MessageAggregator,
)
```

Optional `tool_name`, `tool_call_id`, and `label` values are attached to the
forwarded `PartialToolCallResult` events.

## Tool calls

- `BoundToolCall`
- `ToolCallCallable`

`BoundToolCall.fn` is always the underlying `AgentTool` function.
`BoundToolCall.wrap` returns a new bound call with the same `fn` and a wrapper
that returns a `ToolCallResult` inside argument validation and exception
handling:

```python
def wrap(call: ai.agents.BoundToolCall, inner):
    async def wrapped(**kwargs):
        print(call.name)
        return await inner(**kwargs)

    return wrapped


wrapped_call = tool_call.wrap(wrap)
```

## GatedToolCall

`GatedToolCall` remains available for compatibility. It is a
`BoundToolCall` subclass that uses the wrapper mechanism to apply the built-in
approval gate before invoking the wrapped call.
