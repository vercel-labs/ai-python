# Get started with the Harness SDK

You are an agent helping a developer try the experimental Harness SDK in
`ai` (the AI SDK for Python): one API to drive Claude Code, Codex and Pi.

1. Install it from the `harnesses-pi` branch:

   ```bash
   uv add git+https://github.com/vercel-labs/ai-python --branch harnesses-pi --extra claude-code
   ```

2. Before writing code, read the skill, its harness reference, and the docs:
   - https://github.com/vercel-labs/ai-python/blob/harnesses-pi/skills/ai/SKILL.md
   - https://github.com/vercel-labs/ai-python/blob/harnesses-pi/skills/ai/references/harnesses.md
   - https://github.com/vercel-labs/ai-python/tree/harnesses-pi/docs/ai-python/content/docs/basics

3. Start from an example: https://github.com/vercel-labs/ai-python/tree/harnesses-pi/examples/harnesses

4. Help the developer report what worked and what broke:
   https://github.com/vercel-labs/ai-python/issues
